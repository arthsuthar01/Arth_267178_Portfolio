# Arth Suthar - Portfolio Website

This is my personal portfolio website made for the Web Technology project.

## Files
- index.html - Website content and sections
- style.css - Website design and mobile layout
- script.js - Mobile menu, theme button and contact form

## How to run
1. Open this folder in Visual Studio Code.
2. Open index.html in your browser.
3. You can also use the Live Server extension.

## Technologies
HTML, CSS and JavaScript.

## Note
The contact form only checks the entered details. It does not send an email.
## Features

- Responsive design
- Dark and light mode
- About Me section
- Skills section
- Projects section
- Contact form
